# Tài liệu trình bày Orbit

Thư mục này là nơi duy nhất lưu tài liệu dùng để thuyết trình và demo. Nội dung kỹ thuật canonical nằm trong [`../docs/`](../docs/README.md).

- [`ORBIT_PROJECT_REVIEW_15_SLIDES.md`](ORBIT_PROJECT_REVIEW_15_SLIDES.md) — kịch bản và nguồn nội dung của bài review.
- [`orbit-project-review-15.html`](orbit-project-review-15.html) — deck HTML có thể mở trực tiếp trên trình duyệt hoặc in thành PDF.

Khi cập nhật project review, sửa kịch bản Markdown trước rồi đồng bộ sang bản HTML. Mọi đầu ra trình bày mới đều đặt tại đây.
